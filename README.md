# モコのエコー＆リバーブ PC版 v1.0

![モコのアイコン](icon.png)

歌や声にエコーとリバーブを加える、Windows用のローカル音声ツールです。

## できること

- エコーの量・間隔・繰り返し・明るさを調整
- リバーブの量・部屋の広さ・やわらかさ・響きの始まりを調整
- 7つのプリセットと、原音／効果ありの聞き比べ
- 元のサンプルレートとチャンネル数を保った24bit PCM WAV保存

## 音割れを防ぐ仕組み

最終段リミッターを常時使用し、保存前に必要なら全体の音量を下げてピークを−1dB以下へ調整します。保存したWAVも読み戻して検査します。全7プリセットで保存後ピーク−1.20dBFSを実測しました。元から歪んだ音源の修復や、後段で増幅した音の無歪みを保証するものではありません。

## 動作環境と起動方法

- Windows、Python 3.10（検証済み：3.10.11）、Python Launcherの `py -3.10` が使用可能な環境
- 初回セットアップ時のみ、無料パッケージ取得用のインターネット接続が必要
- M4A等を読み込む場合はFFmpegを別途導入し、PATHへ追加

1. Releaseの `moko-echo-reverb-tool_v1.0.zip` をダウンロードして解凍します。
2. **初回のみ `setup.bat` を実行**し、Setup completeの表示を確認します。配布ZIPにvenvは含みません。
3. `run_tool.bat` で起動し、ブラウザで http://127.0.0.1:7863 を開きます。
4. 音源とプリセットを選び、「効果をかけてWAVに保存」を押します。

設定を変えたらもう一度保存してください。原音・効果ありのプレイヤーで聞き比べできます。元音源は変更しません。完成WAVは `output/処理ごとのフォルダ/元名_echo-reverb.wav` に保存します。終了時は起動したコマンド画面でCtrl+Cを押します。ブラウザを閉じるだけでは終了しません。

入力はモノラル／ステレオ、30分・512MB以内。響きを使う場合は末尾に12秒の余韻を追加し、最後の50msをフェードします。「素のまま」でも安全リミッターは有効です。

## 対応形式

読み込み：WAV／MP3／FLAC／M4Aなど。WAV・MP3・FLACはPedalboardを使用し、直接読めないM4AなどはローカルのFFmpegで変換します。保存：24bit PCM WAV。

## ローカル処理

音源の外部送信や有料サービスは使用しません。Gradioの利用統計は無効、接続先は127.0.0.1のみ、共有URLも無効です。専用環境・キャッシュ・一時ファイルは解凍先のフォルダ内に作られます。

## 仕組みと実測結果


エコーの音だけにローパスをかけ、明るさ0〜1を約1200〜18000Hzのカットオフへ対応付けます（サンプルレートにより上限調整）。Delayはwetのみを生成し、原音に指定量を足します。Reverbもwetのみを生成して加え、wet音だけを指定ms後ろへずらしてプリディレイを実現します。原音の開始位置はずらしません。

最終段にはPedalboard 0.9.26のBrickwallLimiterを常時使用します。天井−1.2dB、リリース100ms、先読み5ms、true_peak検出有効です。通常のLimiterはメイクアップゲインで出力を持ち上げるため、音質とピーク制御を優先して先読み型を選びました。

さらに保存直前にサンプルピークを測定し、−1dBを超える場合だけ全体を減衰します。低い音源を増幅する処理は行いません。24bit量子化の余裕も取り、保存後のWAVを読み戻して−1dB以下・元と同じレート／チャンネル／予定フレーム数・有限値を確認します。不合格のWAVは削除してエラーにします。

結果画面の「音量低下」は最終ピーク調整分です。リミッターによる瞬間的な抑制量とは別です。元から歪んだ音源の修復や、後段で音量を上げた場合の無歪みを保証するものではありません。−1dBはサンプルピークの検証値で、厳密な再構成波形のtrue-peak規格適合を保証する値ではありません。

## 実測結果（2026-11-25）

Python 3.10.11 / Pedalboard 0.9.26 / soundfile 0.14.0 / Gradio 6.32.0 / numpy 2.2.6。専用venv作成・全import成功。

先行テスト：48kHzモノラル、3秒サイン波＋2秒無音。入力−1.938200dB・5秒、Delay＋Reverb＋通常Limiter後0dB、最終調整後の保存WAV−1.000003dB・5秒。最終調整による減衰1.000003dB。

別の実音声 （非公開の検証用音源） の先頭30秒（48kHzモノラル、元ピーク−0.000264dB）で全プリセットを一巡しました。

## 検証スクリプト

`probe.py` はテスト信号を生成して検証します。`verify.py` は検証用の音声を引数で指定して実行します（省略時は `tests/input.wav`）。音声データは同梱しません。検証スクリプトの出力が既に存在する場合は新しい作業用コピーで実行してください。
